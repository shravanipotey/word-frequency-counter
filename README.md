# Word Frequency Counter

A Python program that reads a text file and counts how often each word appears.

## Features
- Converts text to lowercase and removes punctuation
- Counts total and unique words
- Shows the top 5 most frequent words

## Technologies
- Python 3
- File handling, dictionaries, sorting

## How to run
1. Install Python 3
2. Download word_counter.py and sample.txt into the same folder
3. Run: python word_counter.py
